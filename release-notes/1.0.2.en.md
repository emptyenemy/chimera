# Chimera 1.0.2

### Configuration snapshots
- Added manual snapshots of settings and lists.
- Snapshots can be compared in the app and through the CLI to review changes without applying them.
- Settings and list changes now create automatic snapshots that can be used for recovery.

### Appearance
- Added 14 coordinated color palettes, including Classic. The theme catalog is fetched from GitHub with safe caching and updates.
- Save a custom variant based on a selected palette.
- Configure a single accent color with 12 presets, hue selection, or HEX input. Colors are normalized, and text contrast is kept at or above 4.5:1.
- Use the Windows accent color and choose the interface radius and density.
- The theme is applied before the window is drawn, updates live, and can follow the system light or dark theme.

# Chimera 1.1.0

### Auto-setup
- New Auto-setup page: Chimera checks services from your computer, tries strategies, hosts providers, DNS and the proxy on its own, and keeps what makes the sites open. No need to know how a strategy differs from hosts.
- Set up everything fixes all unreachable services at once, Fix handles a single one, and Check shows what opens now and why not: DPI blocking, no DNS or a region refusal.
- Two modes: fast takes the first working option (usually tens of seconds), smart compares every option and picks the fastest.
- Nothing breaks: an option that makes a working service stop opening or cuts internet access is rejected. The original state is saved before the search, Undo restores everything with one button, and after a crash the app restores the settings itself.
- The working option is remembered per network: at home and at work it is tried first next time.
- Fix automatically (optional): if a service auto-setup fixed before stops opening for two checks in a row, Chimera fixes it again on its own.
- While protection is off, the overview offers a Set up automatically button.
- In the terminal: `chimera fix`, with `fix check` to check, `fix youtube --smart` for one service and `fix revert` to undo.

### Fixes
- Turning hosts unblocking off no longer leaves blank lines in the system hosts file; previously they piled up with every on/off switch.

### For agents
- Skill 1.5.0: an agent starts a fix request with `chimera fix check` and fixes with `chimera fix <service>`.

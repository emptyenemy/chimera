# Chimera 1.0.3

### Proxy
- Everything the sing-box core supports now works: Hysteria2, Hysteria, TUIC, AnyTLS, NaiveProxy, WireGuard, SSH, Snell, SOCKS4/5, HTTP and HTTPS join VLESS, VMess, Trojan and Shadowsocks, plus a ready sing-box outbound JSON.
- The link format is detected automatically: paste it together with message text or subscription contents; Telegram SOCKS links work too. The supported formats are listed under the link field.
- Links with a transport sing-box does not have (xhttp, kcp) are now rejected with a clear error instead of becoming a connection that silently fails. Shadowsocks obfs-local and v2ray-plugin plugins are applied.

### Appearance
- Enabled modules on the overview, in the sidebar and on module pages use the selected accent. Green is kept only for success: sites that opened and fast pings.
- The selected tab and the selected option in toggle groups (theme, language, proxy mode and others) are highlighted with the accent and no longer blend in.

### Trials and verified configuration
- Try a strategy, hosts toggle or TUN mode temporarily: after site checks pass, confirm it with "Keep"; otherwise the previous state returns after the selected time.
- Added the last verified configuration: after the selected sites pass a check, settings are saved to a separate pinned snapshot that can be restored in the app or through the CLI.

### Terminal
- The terminal interface has been rebuilt for the keyboard: text menus instead of buttons and switches, arrows or WASD, Enter, digits and Esc.
- Edit site lists right in the terminal: Ctrl+S saves, undo and redo work, and a draft is kept if saving fails.
- The new `chimera explain <address>` command and Ctrl+E in the terminal show why a site takes a route: which lists matched and what DPI bypass, proxy and hosts do with it.
- Press `:` to open a command line with history: CLI commands run inside the terminal interface, secrets are hidden and never stored in history.
- The Telegram proxy link is shown in full in the CLI and terminal interface: `chimera tg link` gives it right away for connecting. Only the proxy link stays hidden.

### Reliability
- Fixed enabling hosts unblocking failing with "Could not save a snapshot" after upgrading from older versions.
- Module settings and core working files (IPSet, PAC, proxy rules) are written as a whole: a failed write no longer leaves an empty or truncated file.
- Quick settings changes no longer overwrite each other, and unsaved Telegram, DNS, port and list edits survive switching pages.
- The accent hue slider no longer lags.
- Site checks keep their results when you leave the page and correctly parse Cyrillic domains and IPv6.
- Proxy link import now handles old Shadowsocks links with IPv6 or `@` in the password; invalid VMess ports are rejected.
- Hosts automation intervals are validated, and the background check no longer runs twice.
- Game filter mode and ports are saved in one step: an invalid range no longer leaves settings half-changed.
- The window opens on double-click in every build variant.
- A narrow window or a wide sidebar no longer clips fields and buttons.

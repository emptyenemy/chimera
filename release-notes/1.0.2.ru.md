# Chimera 1.0.2

### Снимки настроек
- Добавлено создание ручных снимков настроек и списков.
- Снимки можно сравнить в окне приложения и через CLI, чтобы увидеть изменения без применения настроек.
- Перед изменениями настроек и списков автоматически сохраняются снимки для восстановления.
- Исправлена замена файлов приложения при обновлении.

### Оформление
- Добавлены 14 согласованных цветовых палитр, включая классическую. Каталог тем загружается с GitHub с безопасным кешированием и обновлением.
- Можно сохранить собственный вариант на основе выбранной палитры.
- Акцент настраивается одним цветом: доступны 12 пресетов, выбор оттенка и ввод HEX. Цвет нормализуется, а контраст текста поддерживается на уровне не ниже 4,5:1.
- Можно использовать акцентный цвет Windows, выбирать скругления и плотность интерфейса.
- Тема применяется до отрисовки окна, меняется на лету и может переключаться вслед за системной светлой или тёмной темой.

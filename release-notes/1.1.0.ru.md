# Chimera 1.1.0

### Автонастройка
- Новая страница «Автонастройка»: Chimera сама проверяет сервисы с вашего компьютера, перебирает стратегии, hosts-провайдеры, DNS и прокси и оставляет то, при чём сайты открываются. Разбираться, чем стратегия отличается от hosts, не нужно.
- «Настроить всё» чинит все недоступные сервисы сразу, «Починить» — один сервис, «Проверить» показывает, что открывается сейчас и почему нет: блокировка DPI, нет DNS или отказ по стране.
- Два режима: быстрый берёт первый рабочий вариант (обычно десятки секунд), умный сравнивает все и выбирает самый быстрый.
- Ничего не сломается: вариант, при котором перестал открываться работавший сервис или пропал интернет, отбрасывается. Перед подбором сохраняется исходное состояние, «Вернуть как было» возвращает всё одной кнопкой, а после аварии программа восстановит настройки сама.
- Рабочий вариант запоминается для сети: дома и на работе в следующий раз он проверяется первым.
- «Чинить автоматически» (по желанию): если сервис, который автонастройка уже чинила, перестал открываться две проверки подряд, Chimera починит его снова сама и сообщит об этом уведомлением в трее.
- На обзоре, пока защита выключена, есть кнопка «Настроить автоматически».
- В терминале — `chimera fix`: `fix check` для проверки, `fix youtube --smart` для одного сервиса, `fix revert` чтобы вернуть.
- «Поделиться результатом» открывает на GitHub форму issue с отчётом: ваш провайдер и что сработало, без адресов. Из таких отчётов собирается карта провайдеров, и у ваших соседей по провайдеру автонастройка сначала пробует то, что сработало у вас. В терминале — `chimera fix report`.
- В `chimera tui` автонастройка открывается по Ctrl+F или с «Обзора»: ход подбора, итог по сервисам и те же действия, что на странице.

### Прокси
- Адрес подписки провайдера вставляется в поле ссылки прокси: Chimera скачивает её серверы и выбирает самый быстрый. Другой сервер выбирается в списке, подписка обновляется одной кнопкой. Если выбранный сервер перестал отвечать, прокси сам переходит на самый быстрый из работающих. В терминале — `chimera proxy servers`, `server`, `fastest`, `subscription`.
- «Всегда напрямую»: банки, госуслуги и маркетплейсы, которые не пускают зарубежные адреса, идут мимо прокси даже в полном туннеле. Встроенный список подключён сразу, свои списки отмечаются на странице «Прокси». В терминале — `chimera proxy direct`.

### Стратегии и списки по воздуху
- Свежие стратегии и списки сайтов приходят без новой версии программы: «Настройки → Обновление → Стратегии и списки» или `chimera data update`. Списки, которые вы меняли, остаются как есть — предпросмотр покажет, какие именно.

### Исправления
- Проверка сайтов видит блокировку «16 КБ»: раньше сайт, у которого ТСПУ замораживает передачу после первых килобайт, считался открытым, хотя в браузере грузился бесконечно. Теперь это блокировка, и автонастройка подбирает для него рабочий способ.
- Chimera больше не трогает sing-box других программ (Hiddify, NekoBox и т. п.): остановка прокси снимает только свой процесс, а смена ссылки или режима не запускает прокси Chimera поверх чужого клиента.
- Выключение разблокировки hosts больше не оставляет пустые строки в системном файле hosts: раньше они копились при каждом включении и выключении.

### Для агентов
- Скилл 1.5.0: просьбу починить сервис агент начинает с `chimera fix check` и чинит командой `chimera fix <сервис>`.

# Chimera 1.0.1

### Windows editions
- Qt and WebView2 editions include an app window.
- Lite is a compact edition with the CLI, TUI, and browser-based app interface (`--browser`).

### External agent support
- Added a CLI with machine-readable JSON output, error codes, and command levels. `chimera docs` and `chimera agent-info --json` report available commands, protocol versions, and skill compatibility.
- Chimera now ships with an agent skill covering operating rules, secret handling, and version compatibility.

### What’s new
- The app interface has been rebuilt with shadcn/ui. The app and landing page share a frontend and components; Russian and English, plus light and dark themes, are available.
- The background service manages module processes and provides a command channel for the app window and CLI.
- The app’s “What’s New” tab and the landing page’s news section display release notes in Russian and English.
- Configuration sharing lets you choose sections, preview changes, and import settings. Proxy links and Telegram proxy secrets are excluded from exports; a backup is created before applying changes.
- Added configuration snapshot browsing, restore previews, and rollback if a restore fails.
- Changes to `lists/*.txt` are applied automatically by the running app.

# Chimera 1.0.4

### Auto-setup
- New Auto-setup page: Chimera checks services from your computer, tries strategies, hosts providers, DNS and the proxy on its own, and keeps what makes the sites open. No need to know how a strategy differs from hosts.
- Set up everything fixes all unreachable services at once, Fix handles a single one, and Check shows what opens now and why not: DPI blocking, no DNS or a region refusal.
- Two modes: fast takes the first working option (usually tens of seconds), smart compares every option and picks the fastest.
- Nothing breaks: an option that makes a working service stop opening or cuts internet access is rejected. The original state is saved before the search, Undo restores everything with one button, and after a crash the app restores the settings itself.
- The working option is remembered per network: at home and at work it is tried first next time.
- Fix automatically (optional): if a service auto-setup fixed before stops opening for two checks in a row, Chimera fixes it again on its own and tells you with a tray notification.
- While protection is off, the overview offers a Set up automatically button.
- What to try: auto-setup methods (strategies, hosts, DNS, proxy) and single options can be switched off, so the search does not waste time where nothing will help you and the proxy is not used when it costs speed. In the terminal: `chimera fix --only strategy` or `--skip proxy` for one run.
- In the terminal: `chimera fix`, with `fix check` to check, `fix youtube --smart` for one service and `fix revert` to undo.
- “Share the result” opens a GitHub discussion with a report: your provider and what worked, no addresses. These reports build a provider map, so auto-setup tries what worked for you first for others on your provider. In the terminal: `chimera fix report`.
- In `chimera tui`, auto-setup opens with Ctrl+F or from the Overview: search progress, the result per service and the same actions as on the page.

### Proxy
- Paste a provider subscription address into the proxy link field: Chimera downloads its servers and picks the fastest. Pick another server in the list and refresh the subscription with one button. If the chosen server stops answering, the proxy switches to the fastest working one on its own. In the terminal: `chimera proxy servers`, `server`, `fastest`, `subscription`.
- Always direct: banks, government portals and marketplaces that block foreign addresses bypass the proxy even in the full tunnel. The built-in list turns on by itself when your provider is in Russia; check your own lists on the Proxy page. In the terminal: `chimera proxy direct`.
- Sites behind Cloudflare, all at once: the built-in `cloudflare` list routes every such site through the proxy with one checkbox, without adding each one. The Checks page recognizes such sites and suggests a fix by cause: what the censor cuts goes to strategies, without capping speed; what refuses visitors from Russia itself, like DeepL, goes to the proxy. Auto-setup checks and fixes Cloudflare itself.

### Over-the-air strategies and lists
- Fresh strategies and site lists arrive without a new program version: Settings → Updates → Strategies and lists, or `chimera data update`. Lists you changed stay as they are, and the preview shows which ones.

### Lists
- Built-in `tiktok` list: TikTok itself hides new videos from Russian addresses, so the list goes to the proxy, which then carries every TikTok and CDN domain.
- “Record website domains” now checks which of the found domains open and selects the blocked ones itself; you only pick the list.

### Fixes
- Site checks now catch the “16 KB” block: a site whose transfer the DPI froze after the first kilobytes used to count as open while the browser loaded it forever. Now it is a block, and auto-setup finds a working method for it.
- Chimera no longer touches sing-box from other programs (Hiddify, NekoBox and the like): stopping the proxy ends only its own process, and changing the link or mode no longer starts the Chimera proxy over another client.
- Turning hosts unblocking off no longer leaves blank lines in the system hosts file; previously they piled up with every on/off switch.

### For agents
- Skill 1.5.0: an agent starts a fix request with `chimera fix check`, fixes with `chimera fix <service>` and narrows the search when the user knows a method will not help; sites behind Cloudflare go to a strategy first, and `fix report` is never published on the user's behalf.

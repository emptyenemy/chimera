# Раскладка Chimera

Пути указаны от папки программы (при запуске из исходников это корень репозитория, в собранной версии это папка с `Chimera.exe`).

| Путь | Что там | Можно править |
|---|---|---|
| `config.json` | режим интерфейса, движок окна, канал обновлений, игровой фильтр и общие флаги | осторожно, лучше через программу |
| `lists/*.txt` | списки доменов и подсетей по сервисам (discord, youtube, telegram и т. д.); строка `#` — комментарий | да, но см. «Без CLI» в `SKILL.md` |
| `strategies/*.txt` | стратегии winws2: один аргумент на строку | нет, генерируются из стратегий Flowseal |
| `strategies/hostlists/list-general-user.txt`, `ipset-user.txt` | собираются из выбранных списков | нет, перезаписываются |
| `strategies/hostlists/list-exclude-user.txt`, `ipset-exclude-user.txt`, `ipset-all.txt` | пользовательские исключения и ipset | только по просьбе пользователя |
| `data/winws.json` | последняя стратегия, выбранные списки, автозапуск | секретов нет, править лучше через программу |
| `data/proxy.json` | ссылка прокси, режим, списки, приложения, порт | **секрет**: ссылка содержит учётные данные |
| `data/tgproxy.json` | порт, секрет и параметры Telegram-прокси | **секрет** |
| `data/hosts.json` | привязки списков к провайдерам hosts, фоновые опции | да, через программу |
| `data/dns_providers.user.json` | добавленные пользователем DNS-провайдеры | да, через программу |
| `data/singbox-config.json`, `singbox-domains.json`, `singbox-ips.json`, `proxy.pac` | конфиг sing-box, файлы правил и PAC | нет, генерируются |
| `data/logs/*.log` | логи: `winws.log`, `proxy.log`, `tgproxy.log`; `hosts.log`, `service.log` и `update.log` появляются, когда соответствующий модуль работал | только читать |
| `bin/`, `upstream/` | бинарники и внешние проекты | нет |

Папка `data/` создаётся программой и не хранится в git.

## Где живёт состояние

Запущенные процессы (winws2, sing-box, Telegram-прокси) принадлежат либо окну Chimera, либо фоновой службе. Остановить или запустить их можно только через программу или CLI, но не убивая процессы вручную: иначе останутся правила WinDivert и системный прокси.

Блок в системном файле `hosts`, DNS адаптера и системный прокси относятся к состоянию системы, а не к файлам настроек: их откатывают действиями программы (выключить подмену hosts, сбросить DNS, остановить прокси).

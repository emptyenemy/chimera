# Команды chimera (план)

Это заготовка: CLI в разработке (см. `docs/ROADMAP.md`). Все команды ниже запланированы, а не существуют. Перед использованием проверь `chimera --help` и `chimera <команда> --help`, сверяйся с ними, а не с этим файлом. Когда CLI выйдет, файл заменяется справкой по факту.

Общие правила, на которые рассчитан скилл:

- `--json` у каждой команды: машинный вывод вместо текста.
- Коды возврата: `0` успех, ненулевой при ошибке; причина в выводе.
- Команды, которые меняют систему, не спрашивают подтверждения в неинтерактивном режиме, поэтому вызывай их только по просьбе пользователя.

## Состояние и управление

| Команда | Что делает |
|---|---|
| `chimera status` | что запущено, стратегия, списки, версия, права |
| `chimera restart` | перезапустить Chimera |
| `chimera update` | проверить и установить обновление |
| `chimera winws start\|stop [стратегия]` | обход DPI |
| `chimera proxy start\|stop\|mode` | прокси sing-box |
| `chimera tg start\|stop` | Telegram-прокси |
| `chimera hosts on\|off` | подмена hosts |
| `chimera dns set\|reset` | системный DNS |

## Списки и проверки

| Команда | Что делает |
|---|---|
| `chimera lists show\|add\|remove` | списки доменов |
| `chimera check <домен>` | открывается ли домен и заблокирован ли по реестру |
| `chimera fix <сервис>` | подобрать рабочую стратегию, включить, перепроверить |

## Безопасность и отчёты

| Команда | Что делает |
|---|---|
| `chimera backup create\|list\|restore\|diff` | снимки настроек и откат |
| `chimera profile export\|import` | поделиться настройками по разделам |
| `chimera panic` | выключить всё и сбросить hosts, DNS, системный прокси |
| `chimera doctor` | отчёт для issues, секреты замаскированы |
| `chimera path add\|remove` | добавить папку программы в PATH пользователя |

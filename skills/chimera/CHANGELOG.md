# История скилла chimera

Версия скилла живёт отдельно от версии программы. Поле `version` в начале `SKILL.md` повышается, когда меняются правила поведения агента. `requires_protocol` — минимальная версия протокола командной строки, с которой скилл работает. Программа знает диапазон совместимых версий скилла (`skill_compat` в `chimera agent-info`).

## 1.4.0

Ссылка и секрет Telegram-прокси больше не секреты: программа показывает их всегда, агент может отдать их пользователю для подключения Telegram. Ссылка прокси по-прежнему скрыта и открывается `--show-secrets` только по просьбе пользователя. Совместимо с 1.3.0; протокол не менялся.

## 1.3.0

Программа заговорила на нескольких языках. Разбирать вывод нужно по `ok`, `error.code` и `error.key`, а не по тексту: текст зависит от языка (флаг `--lang` на один вызов), коды и ключи нет. Языка пользователя без просьбы не менять. Совместимо с 1.2.0; протокол не менялся (поля в `--json` только добавлены).

## 1.2.0

Списки доменов можно править файлом: программа подхватывает правку сама. Как проверить результат (проверка списков, журнал изменений с источником `file`) и какие файлы так править нельзя. Совместимо с 1.1.0; протокол не менялся.

## 1.1.0

Поведение для новых команд: сначала `doctor`, DNS через `dns trial`, `panic` только по просьбе пользователя, чужой конфиг только через предпросмотр и с явным согласием на пункты, требующие подтверждения. Совместимо с 1.0.0; протокол не менялся.

## 1.0.0

Первая версия: порядок действий, поиск причины, правила изменений, уровни команд, секреты, обработка несовпадения версий. Справочник команд и файлов в скилл не входит: его выдаёт `chimera docs`.

# Пробное применение

С версии 1.0.3 можно временно применить стратегию, включить
или выключить текущую подмену hosts, попробовать полный или выборочный TUN.
В окне кнопка «Попробовать» находится на странице соответствующего модуля.
Смена привязок списков к поставщикам hosts пока выполняется обычным способом.

Перед применением сохраняются состояние модуля и обычный снимок в истории бэкапов.
Можно выбрать от 15 до 300 секунд и от одного до шести контрольных доменов.
По умолчанию — 60 секунд, `example.com` и `cloudflare.com`; для своей задачи лучше
указать нужные сайты. Доступность проверяется через применённый способ подключения.
Успешная HTTP-проверка, включая страницу браузерной проверки, позволяет подтвердить
пробу. Она не гарантирует скорость соединения или работу всех функций сайта.

«Оставить» становится доступно после успешных проверок. «Вернуть» доступно сразу.
Ошибка контрольной проверки или истечение времени возвращает прежнее состояние:
включённость, выбранную стратегию или режим прокси. Для hosts восстанавливается
только блок Chimera; сторонние строки сохраняются.

Одновременно выполняется одна проба. До её завершения другие изменения настроек
блокируются, фоновое обновление hosts приостанавливается, правки списков ожидают
завершения пробы. Навигация и аварийное выключение остаются доступны.

Таймер работает у владельца модулей: приложения или службы. Закрытие клиентского
окна и выход из CLI не подтверждают пробу. При завершении приложения без службы
проба откатывается. После аварии незавершённая запись `data/trial.json` позволяет
владельцу восстановить состояние при следующем запуске. Чужие процессы не
останавливаются; ошибка отката остаётся видимой и блокирует новые изменения.
Можно повторить откат или восстановить проверенный снимок через настройки.
«Выключить всё» отменяет пробу без повторного включения модулей таймером.

## CLI

```powershell
chimera trial start strategy general --seconds 60 --domains example.com,cloudflare.com
chimera trial start hosts on
chimera trial start tun split --seconds 30
chimera trial state --json
chimera trial confirm <id>
chimera trial revert <id>
```

Идентификатор возвращается в `active.id`; подтверждение должно поступить до
истечения времени. Системные изменения требуют прав администратора.

## TUI

На странице стратегий, hosts или прокси: `Ctrl+T` — начать пробу,
`Ctrl+K` — оставить, `Ctrl+R` — вернуть. Стратегия берётся из выбранной строки;
hosts переключаются в противоположное состояние; на странице прокси пробуется
выборочный TUN, если выбран этот режим, иначе полный TUN. Таймер и подсказка
показываются над содержимым независимо от открытого раздела.

DNS использует собственную существующую пробу для выбранного адаптера.

## Проверка разработки

```powershell
python -m pytest tests/test_trials.py tests/test_trial_ops.py tests/test_tui_textual.py
python tools/smoke_trials.py --screenshot trial.png
```

Сценарий окна использует настоящий API, отдельные данные и имитацию процессов,
hosts и сети. Он не меняет системный hosts, DNS, маршруты или прокси Windows.

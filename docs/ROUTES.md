# Разбор маршрута

Реализовано в исходниках следующего обновления. Команда объясняет сохранённые правила
Chimera для домена или IP: совпадения в списках с номерами строк, выбранный маршрут
прокси, состояние DPI и записи системного hosts. Настройки не меняются, DNS-запросы
и проверки доступности не выполняются. Нужна работающая Chimera или её служба.

```text
chimera explain youtube.com
chimera explain api.example.com --app Discord.exe
chimera explain 192.168.1.1 --app chrome.exe --json
```

В терминальном интерфейсе — Ctrl+E из любого раздела или пункт «Разобрать маршрут сайта»
в Обзоре. Enter принимает адрес, стрелки и PgUp/PgDn читают отчёт, F5 перечитывает
правила, Esc возвращает в прежний раздел.

Домены в списках прокси и DPI покрывают и поддомены: `example.com` совпадает с
`api.example.com`, но не с `badexample.com`. Назначение списка для Hosts относится
к точным именам: наличие `example.com` не добавляет в hosts все его поддомены.
Отчёт показывает записи внутри и вне блока Chimera, включая разные адреса для
одного имени.

Для полного TUN списки не ограничивают охват. В выборочном TUN сначала действует
исключение локальных адресов, затем правило приложения и правила списков. `--app`
проверяет точное имя процесса. При остановленном прокси отчёт отдельно показывает
сохранённое правило, которое будет использовано после запуска. Правила внешнего
sing-box или winws считаются неизвестными.

PAC зависит от поддержки системного прокси приложением и допускает прямой маршрут
при отказе SOCKS. IPv6-подсети шире одного адреса не проверяются нашим PAC-файлом;
они работают в TUN. Для домена неизвестны текущие DNS-адреса, поэтому отчёт явно
указывает, когда IP или имя приложения могут изменить маршрут. Пользовательские
списки DPI не описывают все фильтры самой стратегии.

Семантика TUN сверена с [правилами sing-box](https://sing-box.sagernet.org/configuration/route/rule/),
[проверкой непубличных адресов](https://github.com/SagerNet/sing/blob/v0.7.0/common/network/addr.go)
и [совпадением имени процесса](https://github.com/SagerNet/sing-box/blob/v1.12.0/route/rule/rule_item_process_name.go).

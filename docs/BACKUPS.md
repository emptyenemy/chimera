# Бэкапы и восстановление

Снимок создаётся перед применением импортированного конфига и перед восстановлением.
Он содержит затрагиваемые настройки и списки, а не полный образ компьютера.
Хранится до десяти снимков в `data/backups/`.

## В окне

**Настройки → Инструменты → Бэкапы настроек → Открыть бэкапы.**

1. Выберите снимок и откройте предпросмотр.
2. Проверьте разделы и изменения. Повреждённый снимок применить нельзя.
3. Нажмите «Восстановить». Сначала сохраняется текущее состояние, затем применяются
   настройки снимка. При ошибке программа пытается вернуть состояние до восстановления
   и показывает результат отката.

Изменения применяются через менеджеры программы к работающим модулям. Остановленные
модули восстановление само не запускает. Параметры режима запуска и движка окна
вступают в силу при следующем запуске.

## Через CLI

```powershell
chimera config backups
chimera config restore-preview 20260930-120000-001-import
chimera config restore 20260930-120000-001-import --confirm
```

`--json` доступен у всех трёх команд. Первые две только читают; восстановление требует
явного `--confirm`. Если применяемые настройки затрагивают системные инструменты,
понадобятся права администратора. Команда работает и через фоновую службу.

## Совместимость снимков

- Старые папки `*-import` поддерживаются. В них были только копии существовавших файлов:
  какие списки появились после импорта, они не фиксировали. Поэтому восстановление такого
  снимка возвращает сохранённые настройки и списки, но не обещает удалить новые списки.
  IPSet стратегий в старых снимках также не сохранялся. Эти ограничения показываются
  в предпросмотре.
- Новые снимки содержат манифест, хеши файлов и отметки об отсутствовавших списках.
  Восстановление удаляет списки, созданные соответствующим импортом, и возвращает
  зависимые настройки и сохранённый IPSet стратегий. Снимок перед восстановлением
  позволяет отменить это действие.
- Локальные бэкапы содержат сохранённые ссылки прокси и секреты. Предпросмотр и вывод CLI
  показывают только факт их изменения. Для передачи настроек друзьям предназначен экспорт
  `.chimera`, который исключает эти секреты.

Общие ручные бэкапы и автоматические снимки перед каждым изменением — дальнейшая очередь
в [роадмапе](ROADMAP.md).
